# Security policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues.

Use the repository's **Security** tab to submit a private vulnerability report through GitHub
Security Advisories. Include the affected SDK and version, impact, reproduction steps, and any
suggested mitigation.

We will acknowledge a report as soon as practical, keep reporters informed while it is assessed,
and coordinate disclosure after a fix is available.

Never include production credentials, access tokens, refresh tokens, client secrets, or personal
data in a report. Use redacted or synthetic values.
